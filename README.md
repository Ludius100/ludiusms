# ludiusms
Darmowa, samodzielnie hostowana platforma prywatnego serwera multimediów, zaprojektowana z myślą o Oracle Cloud Always Free.

Cześć, stworzyłem to na początku jako szczątki discord bota na platformie Oracle Cloud. Z uwagi, że Always Free dają 200GB darmowej przestrzeni (de facto 150GB do uzytku jako wolumin danych), stwierdziłem, że może postawie mały NAS na moje Lost Media. 
Po jakimś czasie tak się wkręciłem, że stowrzyłem przy pomocy ChatGPT funkcjonalny serwer z filmami i serialami, które chce zachować/oglądać.


Postanowiłem nad tym nieco dłużej pracować, spróbować doprowadzić to do całkiem dobrze działającego, i przede wszystkim DARMOWEGO oprogramowania do stawiania własnego serwera, przy pomocy Oracle Always Free.
Może komuś się przyda :)
